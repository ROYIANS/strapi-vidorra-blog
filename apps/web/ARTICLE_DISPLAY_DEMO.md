# 文章列表展示效果说明

## 更新内容

已更新文章列表展示逻辑，使用 **`displayMode`** 字段明确控制展示模式。

## 展示模式控制

### 新增字段：`displayMode`
- **`'large'`**：大图模式（必须有 `cover` 封面图）
- **`'normal'`** 或 **不设置**：普通小图模式（可以有或没有 `cover` 和 `description`）

### 描述文本行数限制
为了保持卡片高度一致，避免排版错乱：
- **大图模式**：描述最多显示 **3 行**（`line-clamp-3`）
- **小图模式**：描述最多显示 **2 行**（`line-clamp-2`）
- 超出部分自动截断并显示省略号

### 为什么需要 displayMode？
**问题**：之前根据 `cover + description` 自动判断，导致：
- ❌ 无法让有封面和描述的文章使用小图模式
- ❌ 要用小图模式就必须舍弃封面或描述

**解决**：添加 `displayMode` 字段明确控制：
- ✅ 小图模式可以同时有封面和描述（如文章 2, 5, 8, 10）
- ✅ 大图模式必须有封面图（强制要求）
- ✅ 灵活控制每篇文章的展示形式
- ✅ 描述行数限制保证排版一致性

## 展示的文章类型

### 1. 大图模式（3篇）
**控制条件**：`displayMode: 'large'` + 必须有 `cover`
- **文章 1**: "Next.js 14 完全指南" - 带推荐角标⭐，有封面+描述
- **文章 4**: "Web 性能优化全面指南" - 有封面+超长描述（>80字）
- **文章 7**: "React 中的设计模式实践" - 带推荐角标⭐，有封面+描述

**效果**：
- 占据整行宽度（`basis-full`）
- 背景是模糊的封面图片（`fixed` 视差效果）
- 白色文字叠加在半透明黑色遮罩上
- **描述限制 3 行**，超出部分省略
- 推荐文章左上角显示橙色星星图标 ⭐

### 2. 小图模式 - 有封面 + 有描述（4篇）
**控制条件**：`displayMode: 'normal'` + 有 `cover` + 有 `description`

**重点**：这些文章证明了小图模式可以同时拥有封面和描述！

- **文章 2**: "如何设计一个优雅的主题系统" - 带推荐角标⭐
- **文章 5**: "React Hooks 深度解析"
- **文章 8**: "CSS Grid 布局完全指南"
- **文章 10**: "Docker 容器化实战"

**效果**：
- 左侧：日期方块（显示日期和月份）
- 右侧：标题 + 描述 + 元信息
- **描述限制 2 行**，超出部分省略
- **Hover 效果**：封面图从下方（`top-[100%]`）平滑滑动到顶部（`top-0`），500ms 动画
- 推荐文章左侧显示橙色星星图标 ⭐

### 3. 小图模式 - 无封面（3篇）
**控制条件**：没有 `cover` 或 `displayMode: 'normal'`
- **文章 3**: "JavaScript 开发技巧精选"
- **文章 6**: "TypeScript 高级类型技巧"
- **文章 9**: "Node.js 最佳实践"

**效果**：
- 左侧：日期方块（无图片滑入效果）
- 右侧：标题 + 描述（如果有）+ 元信息
- 标题 hover 显示下划线

## 布局规则

### 占据整行的情况
1. `displayMode: 'large'` - 大图模式
2. `description.length > 80` - 描述超过 80 字（自动全宽显示）

### 两列布局的情况
- 其他所有情况（`basis-1/2`，每行 2 篇）

## 推荐角标说明

带 `recommend: true` 的文章会在左侧显示橙色星星图标：
- **浅色模式**：`text-orange-500`
- **深色模式**：`text-orange-900`
- **位置**：卡片左上角/左侧

当前有推荐角标的文章：
1. 文章 1: Next.js 14 完全指南（大图模式）
2. 文章 2: 如何设计一个优雅的主题系统（小图模式）
3. 文章 7: React 中的设计模式实践（大图模式）

## 响应式布局

### 桌面端（>1024px）
- 每行显示 2 列（`basis-1/2`）
- 大图模式/长描述占据整行（`basis-full`）

### 移动端（<1024px）
- 单列堆叠显示
- 大图模式左右扩展（`-mx-6`）

## 交互效果

### 1. 小图模式 Hover
- **封面图片**：从下方滑入（500ms 过渡动画）
- **标题**：显示下划线

### 2. 大图模式 Hover
- **标题**：显示下划线

### 3. 描述文本截断
- **大图模式**：使用 `line-clamp-3` 限制为 3 行
- **小图模式**：使用 `line-clamp-2` 限制为 2 行
- 超出部分自动显示省略号（`...`）
- 保证卡片高度一致，避免排版错乱

### 4. 分类导航
- 支持水平滚动
- 显示滚动按钮（左/右切换）

## 类型定义

```typescript
interface Post {
  // ... 其他字段
  displayMode?: 'large' | 'normal' // 展示模式控制
  recommend?: boolean // 推荐标记
}
```

## 使用示例

```typescript
// 大图模式（必须有封面）
{
  displayMode: 'large',
  cover: 'https://...',
  description: '...',
  // ...
}

// 小图模式（可以有封面和描述）
{
  displayMode: 'normal', // 或不设置
  cover: 'https://...',  // 可选
  description: '...',    // 可选
  // ...
}
```
